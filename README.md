## 📖 About

99 Nights in the Forest is a co-op survival horror where players must gather resources and survive creatures in a procedurally generated forest. The Resource ESP overlay reveals hidden item locations, resource nodes, and chest positions across the map in real time.

## ⚠️ Visibility Problems

| Problem | Status |
|---------|--------|
| Critical resources spawn randomly with no visual indicators on the map | ✅ Resolved |
| Nighttime visibility near zero making resource gathering dangerous | ✅ Resolved |
| Enemy creature positions unknown until dangerously close proximity | ✅ Resolved |
| Safe path routing through creature-patrolled areas requires guesswork | ✅ Resolved |
| Rare crafting materials hidden in off-path locations players routinely miss | ✅ Resolved |

## ✅ Solution

**99 Nights in the Forest Resource ESP** resolves all visibility and awareness problems with a clean external overlay that never modifies game files.

## 🎯 Features

- Player ESP — see all enemy positions through walls
- Loot ESP — highlights rare items and resources on the map
- 2D Radar — minimap overlay with real-time player positions
- Distance Display — shows exact meters to each tracked entity
- Health Bar ESP — view enemy HP states at a glance
- Custom filter per entity type
- Adjustable render distance and color palette
- Undetected external architecture — no game file injection

## 🚀 Quick Start
